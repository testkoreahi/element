# ELEMENT

Korea University High School
![i wanna go](https://www.korea.ac.kr/sites/ko/images/contents/symbol_1.png)

## About

Element is a game that you can use many different kinds of elements to fight with another; for instance, you can use fire element skill to deal DOT etc.

## Rules

You would get 2 different cards first.   
You can use and change them.
Map would be shrinking.
